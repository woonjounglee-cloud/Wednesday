# Database Files

이 폴더에 Excel 데이터 파일을 저장할 수 있지만, **브라우저에서 직접 HTML 파일을 열 경우 보안상의 이유로 로컬 파일에 접근할 수 없습니다.**

## 🚀 사용 방법

### 방법 1: CSV 파일 업로드 (DRM 파일용 - 권장)

**DRM이 걸린 Excel 파일은 브라우저에서 읽을 수 없으므로 CSV로 변환하세요!**

#### 1단계: Excel 파일을 CSV로 변환

1. **Excel에서 Home_IRP.xlsx 파일 열기**
2. **각 시트를 개별 CSV 파일로 저장**:
   - ROI 시트 → 우클릭 → "시트 이동/복사" → 새 통합 문서 → 저장 → CSV UTF-8 형식으로 저장 → `Home_IRP_ROI.csv`
   - Balance 시트 → 같은 방법 → `Home_IRP_Balance.csv`
   - Portfolio 시트 → 같은 방법 → `Home_IRP_Portfolio.csv`

   또는 더 간단하게:
   - 각 시트를 활성화한 상태에서 "다른 이름으로 저장" → **CSV UTF-8 (쉼표로 분리) (*.csv)** 선택

3. **3개의 CSV 파일 생성**:
   - `Home_IRP_ROI.csv`
   - `Home_IRP_Balance.csv`
   - `Home_IRP_Portfolio.csv`

#### 2단계: CSV 파일 업로드

1. `wednesday-portfolio.html` 파일을 브라우저에서 엽니다
2. 상단의 **"📄 CSV 파일들"** 버튼을 클릭합니다
3. **3개의 CSV 파일을 모두 선택**합니다 (Ctrl 또는 Cmd 키를 누른 채 클릭)
4. 데이터가 자동으로 로드되고 LocalStorage에 저장됩니다

**주의**: 파일 이름에 **ROI**, **Balance**, **Portfolio** 키워드가 포함되어야 합니다!

### 방법 2: Excel 파일 업로드 (DRM이 없는 파일)

1. `wednesday-portfolio.html` 파일을 브라우저에서 엽니다
2. 상단의 **"📁 Excel 파일"** 버튼을 클릭합니다
3. `Home_IRP.xlsx`, `WJ_ISA.xlsx` 등의 파일을 선택합니다
4. 데이터가 자동으로 로드되고 LocalStorage에 저장됩니다

### 방법 3: ETF/주식 종가 업데이트

1. 상단의 **"💰 ETF 종가"** 버튼을 클릭합니다
2. `data_ETF_YYYYMMDD.xlsx` 또는 `.csv` 파일을 선택합니다
3. 현재 ROI 테이블의 종가가 자동으로 업데이트됩니다

## 🐛 문제 해결

### DRM이 걸린 파일을 업로드할 수 없어요
- ✅ **해결**: Excel 파일을 CSV로 변환해서 업로드하세요 (위의 "방법 1" 참조)
- CSV 파일은 DRM의 영향을 받지 않습니다

### CSV 파일 이름 규칙
파일 이름에 다음 키워드가 **반드시** 포함되어야 합니다:
- `ROI` 또는 `roi` (예: Home_IRP_ROI.csv, roi.csv)
- `Balance` 또는 `balance` (예: Home_IRP_Balance.csv, balance.csv)
- `Portfolio` 또는 `portfolio` (예: Home_IRP_Portfolio.csv, portfolio.csv)

### 브라우저 콘솔에서 상세한 로그 확인하기
1. F12 키를 눌러 개발자 도구를 엽니다
2. "Console" 탭을 선택합니다
3. 파일을 업로드하면 다음과 같은 로그를 확인할 수 있습니다:
   - 📄 업로드된 파일 목록
   - 📋 파일 분류 결과
   - ✅ 각 시트의 데이터 개수
   - 📊 최종 데이터 통계
   - ❌ 에러 메시지 (문제가 있을 경우)

### LocalStorage 초기화하기
브라우저의 LocalStorage를 초기화하려면:
1. F12 키를 눌러 개발자 도구를 엽니다
2. "Application" 또는 "Storage" 탭을 선택합니다
3. "Local Storage"를 찾아서 데이터를 삭제합니다

## 📝 참고사항

- **LocalStorage 우선**: LocalStorage에 데이터가 저장되어 있으면 파일 업로드 없이 바로 표시됩니다
- **데이터 영속성**: 브라우저를 닫아도 LocalStorage의 데이터는 유지됩니다
- **웹 서버 사용**: 웹 서버를 통해 HTML을 제공하면 `/db/` 폴더의 파일을 자동으로 로드할 수 있습니다
