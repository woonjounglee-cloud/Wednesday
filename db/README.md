# Database Files

이 폴더에 Excel 데이터 파일을 저장할 수 있지만, **브라우저에서 직접 HTML 파일을 열 경우 보안상의 이유로 로컬 파일에 접근할 수 없습니다.**

## 🚀 사용 방법

### 1. 초기 데이터 업로드 (권장)

1. `wednesday-portfolio.html` 파일을 브라우저에서 엽니다
2. 상단의 **"📁 초기 데이터"** 버튼을 클릭합니다
3. `Home_IRP.xlsx`, `WJ_ISA.xlsx` 등의 파일을 선택합니다
4. 데이터가 자동으로 로드되고 LocalStorage에 저장됩니다

### 2. ETF/주식 종가 업데이트

1. 상단의 **"📄 ETF 종가"** 또는 **"📈 주식 종가"** 버튼을 클릭합니다
2. `data_ETF_YYYYMMDD.xlsx` 형식의 파일을 선택합니다
3. 현재 ROI 테이블의 종가가 자동으로 업데이트됩니다

## 📊 Excel 파일 형식

### 초기 데이터 파일 (Home_IRP.xlsx, WJ_ISA.xlsx 등)

각 Excel 파일은 다음 3개의 시트를 포함해야 합니다:

#### 1. ROI 시트

| 종목코드 | 종목명 | 초기투자금 | 수량 | 종가 | 평가금 | 수익률 |
|---------|--------|-----------|------|------|--------|--------|
| 449170 | TIGER KOFR금리액티브(합성) | 5,504,005 | 52 | 110,212 | 5,731,024 | 4.1% |
| 411060 | ACE KRX금현물 | 1,942,055 | 85 | 27,185 | 2,310,725 | 19.0% |

**참고:**
- 종목코드: 숫자 또는 문자열 (예: "0046A0")
- 초기투자금, 종가, 평가금: 숫자 또는 콤마가 포함된 문자열 (예: "5,504,005")
- 수익률: 백분율 문자열 (예: "4.1%") 또는 소수 (자동 계산됨)

#### 2. Balance 시트

| 날짜 | 투자원금 | 추가납입 | 잔고 | 수익률 |
|------|---------|---------|------|--------|
| 20251116 | ₩16,940,870 | 0 | ₩18,360,634 | 8.4% |

**참고:**
- 날짜: YYYYMMDD 형식 (예: "20251116")
- 금액: 숫자 또는 통화 기호가 포함된 문자열 (예: "₩16,940,870")
- 수익률: 백분율 문자열 (예: "8.4%")

#### 3. Portfolio 시트

| 종목코드 | 종목명 | 자산군 | 구분 | 세팅비중 | 현재비중 | 녹색매수 |
|---------|--------|--------|------|---------|---------|---------|
| 449170 | TIGER KOFR금리액티브(합성) | 현금 | 안전자산 | 10.0% | 31.2% | (3,894,961) |
| 411060 | ACE KRX금현물 | 금 | 대체자산 | 15.0% | 12.6% | 443,370 |

**참고:**
- 종목코드: ROI 시트와 동일한 값
- 자산군: 현금, 금, 채권, 주식 등
- 구분: 세부 분류
- 세팅비중: 목표 비율 (백분율, 예: "10.0%")
- 현재비중: 자동 계산됨
- 녹색매수: 자동 계산됨 (리밸런싱 금액)

## 🐛 문제 해결

### DRM이 걸린 파일을 업로드할 수 없어요
- DRM이 걸린 Excel 파일은 브라우저에서 읽을 수 없습니다
- 해결 방법: 파일을 다른 이름으로 저장하거나, DRM을 제거한 복사본을 만드세요

### 브라우저 콘솔에서 상세한 로그 확인하기
1. F12 키를 눌러 개발자 도구를 엽니다
2. "Console" 탭을 선택합니다
3. 파일을 업로드하면 다음과 같은 로그를 확인할 수 있습니다:
   - 📊 Excel 시트 목록
   - ✅ ROI/Balance/Portfolio 데이터 개수
   - 📋 첫 번째 행 데이터 샘플
   - ❌ 에러 메시지 (문제가 있을 경우)

### LocalStorage 초기화하기
브라우저의 LocalStorage를 초기화하려면:
1. F12 키를 눌러 개발자 도구를 엽니다
2. "Application" 또는 "Storage" 탭을 선택합니다
3. "Local Storage"를 찾아서 데이터를 삭제합니다

## 📝 참고사항

- **LocalStorage 우선**: LocalStorage에 데이터가 저장되어 있으면 Excel 파일 대신 LocalStorage의 데이터를 사용합니다
- **데이터 영속성**: 브라우저를 닫아도 LocalStorage의 데이터는 유지됩니다
- **웹 서버 사용**: 웹 서버를 통해 HTML을 제공하면 `/db/` 폴더의 파일을 자동으로 로드할 수 있습니다
