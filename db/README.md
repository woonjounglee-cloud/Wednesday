# Database Files

이 폴더에 Excel 데이터 파일을 저장하세요:

- `Home_IRP.xlsx` - Home IRP 포트폴리오 데이터
- `WJ_ISA.xlsx` - WJ ISA 포트폴리오 데이터
- `WJ_Stock.xlsx` - WJ 주식 포트폴리오 데이터
- `MG_IRP.xlsx` - MG IRP 포트폴리오 데이터
- `MG_Pension.xlsx` - MG 개인연금 포트폴리오 데이터

## Excel 파일 형식

각 Excel 파일은 다음 시트를 포함해야 합니다:

### ROI 시트
| 종목코드 | 종목명 | 초기투자금 | 수량 | 종가 |
|---------|--------|-----------|------|------|

### Balance 시트
| 날짜 | 투자원금 | 추가납입 | 잔고 | 수익률 |
|------|---------|---------|------|--------|

### Portfolio 시트
| 종목코드 | 종목명 | 자산군 | 구분 | 세팅비중 |
|---------|--------|--------|------|---------|
