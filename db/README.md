# Database Files

## 🎯 가장 쉬운 방법: 복사-붙여넣기 (DRM 파일 OK!)

**DRM으로 보호된 파일도 사용 가능한 가장 간단한 방법입니다!**

### 사용 방법:

1. **Excel 파일 열기**
   - DRM이 걸린 `Home_IRP.xlsx` 파일을 Excel에서 엽니다

2. **데이터 복사**
   - **ROI 시트**: 헤더 포함해서 전체 데이터 선택 → Ctrl+C (또는 Cmd+C)
   - **Balance 시트**: 헤더 포함해서 전체 데이터 선택 → Ctrl+C
   - **Portfolio 시트**: 헤더 포함해서 전체 데이터 선택 → Ctrl+C

3. **웹 앱에서 붙여넣기**
   - `wednesday-portfolio.html` 파일을 브라우저에서 엽니다
   - 상단의 **"📋 데이터 붙여넣기"** 버튼을 클릭합니다
   - 각 섹션에 복사한 데이터를 붙여넣습니다 (Ctrl+V)
   - **"📥 데이터 가져오기"** 버튼을 클릭합니다

4. ✅ **완료!** 데이터가 화면에 표시되고 자동으로 저장됩니다

### 장점:
- ✅ **DRM 파일도 OK**: 파일을 저장할 필요 없이 바로 복사-붙여넣기
- ✅ **가장 간단**: 클릭 3번이면 끝!
- ✅ **안전**: 파일 업로드 필요 없음
- ✅ **빠름**: 몇 초 안에 완료

## 🐛 문제 해결

### Q: DRM이 걸린 파일을 업로드할 수 없어요
**A**: ✅ **"📋 데이터 붙여넣기"** 기능을 사용하세요! 파일을 저장하지 않고 Excel에서 직접 복사-붙여넣기하면 됩니다.

### Q: CSV 파일에도 DRM이 걸려있어요
**A**: ✅ **"📋 데이터 붙여넣기"** 기능을 사용하세요! 파일 저장이 필요 없습니다.

### Q: 붙여넣기가 잘 안돼요
**A**:
1. Excel에서 데이터를 선택할 때 **헤더 행도 함께** 선택했는지 확인하세요
2. 복사할 때 **Ctrl+C** (Windows) 또는 **Cmd+C** (Mac)를 사용하세요
3. 붙여넣을 때 **Ctrl+V** (Windows) 또는 **Cmd+V** (Mac)를 사용하세요
4. 브라우저 콘솔(F12)에서 에러 메시지를 확인하세요

### 브라우저 콘솔에서 상세한 로그 확인하기
1. F12 키를 눌러 개발자 도구를 엽니다
2. "Console" 탭을 선택합니다
3. 데이터를 가져오면 다음과 같은 로그를 확인할 수 있습니다:
   - 📋 붙여넣기 데이터 가져오기 시작
   - 🔄 ROI/Balance/Portfolio 데이터 파싱 중
   - ✅ 각 섹션의 데이터 행 수
   - 📊 최종 데이터 통계
   - ❌ 에러 메시지 (문제가 있을 경우)

### LocalStorage 초기화하기
브라우저의 LocalStorage를 초기화하려면:
1. F12 키를 눌러 개발자 도구를 엽니다
2. "Application" 또는 "Storage" 탭을 선택합니다
3. "Local Storage"를 찾아서 데이터를 삭제합니다

## 💡 팁

### 한 번에 모든 데이터 붙여넣기
- ROI, Balance, Portfolio 데이터를 각각 복사해서 한 번에 모두 붙여넣을 수 있습니다
- 필요한 섹션만 붙여넣어도 됩니다 (예: ROI만 업데이트)

### 여러 탭 데이터 관리
- Home IRP 탭에서 데이터 붙여넣기 → 자동으로 Home_IRP로 저장
- WJ ISA 탭에서 데이터 붙여넣기 → 자동으로 WJ_ISA로 저장
- 각 탭마다 독립적으로 데이터 관리됩니다

### Excel에서 효율적으로 복사하기
1. 시트 탭 클릭
2. Ctrl+A (전체 선택) - 빈 셀이 많으면 데이터 범위만 선택
3. Ctrl+C (복사)
4. 웹 앱에서 Ctrl+V (붙여넣기)

## 📝 참고사항

- **LocalStorage 우선**: LocalStorage에 데이터가 저장되어 있으면 파일 업로드 없이 바로 표시됩니다
- **데이터 영속성**: 브라우저를 닫아도 LocalStorage의 데이터는 유지됩니다
- **웹 서버 사용**: 웹 서버를 통해 HTML을 제공하면 `/db/` 폴더의 파일을 자동으로 로드할 수 있습니다
- **DRM 우회**: 복사-붙여넣기 기능은 DRM을 우회하는 것이 아니라, Excel에서 이미 열린 데이터를 클립보드를 통해 전달하는 것입니다 (합법적인 방법)
